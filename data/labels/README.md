# Label data

This is where real, sourced labels live. See [ADR 0002](../../docs/adr/0002-labels-require-a-cited-source.md)
for why every entry here has a `source`, enforced by `@opentrace/core`'s types — there is no
code path that writes a `Label` or `Tag` without one.

## What's here today

- **`ofac-sdn.json`** — generated by `npm run ingest:ofac` (`scripts/ingest-ofac-sdn.ts`). Pulls
  the real, current U.S. Treasury OFAC Specially Designated Nationals (SDN) list and extracts
  every digital-currency address tagged for a chain this project supports (currently Ethereum and
  Solana — OFAC's list also includes Bitcoin, Tron, Monero, and others this project doesn't have a
  chain adapter for yet, so those are skipped, not mislabeled onto the wrong chain).
  - Every entry: `confidence: "verified"` (OFAC's own published, human-curated list — not a
    probabilistic guess), `source.url` pointing at OFAC's sanctions search tool, `source.addedAt`
    set to the date the script last ran.
  - Every sanctioned address also gets a `"sanctioned"` `Tag`, independent of its `Label`.
  - Re-run `npm run ingest:ofac` any time to refresh against the live list — OFAC updates it
    continuously, so a long-stale copy of this file will miss recent designations or (less
    often) include a delisted one.

## Format

A JSON file matching `{ labels: Label[], tags: Tag[], entities: Entity[] }` — see
`packages/core/src/types.ts` and `packages/core/src/store.ts`.

## Adding a new label source

1. Confirm it's genuinely public and checkable — a URL someone else could open, or a named
   document.
2. Write an ingestion script under `scripts/` (follow `ingest-ofac-sdn.ts`'s shape) that produces
   real `Label`/`Tag` entries with that source, or hand-author a small JSON file in this format
   for a one-off batch.
3. If it's large or updates on its own schedule, don't commit the generated output as the only
   copy of truth — commit the ingestion script, and document in this README how/when to re-run
   it, the way `ofac-sdn.json` does above.
4. Never hand-write a `Label`/`Tag` with a placeholder or guessed `source.url` to get past the
   type system — that defeats the entire point of this file. See `CONTRIBUTING.md`.

## Known gaps (real, disclosed)

- Coverage is small — 89 addresses across two chains, from one source. This is a seed, not a
  claim of comprehensive coverage. Arkham's own labelset took years and 3.9 billion rows; this
  project is one focused day old.
- Stablecoin addresses in the OFAC list (`USDT`/`USDC`) are skipped — OFAC doesn't record which
  chain a stablecoin address is actually on, and guessing would risk mislabeling an address that
  belongs to an unsupported chain as if it were Ethereum or Solana.
